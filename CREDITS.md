# Credits and licences

## Training data (for the shipped weights)
The four shipped models (b16C, u32M, u64M, b16O in img/remote/night/) were trained on these photographs only.
Each photograph was cropped, shrunk to 64x64 pixels (and to 32x32 and 16x16) and reduced to a fixed palette of 256
colours before training. No photograph is included in this repository; the model files hold only the trained numbers.
The licensors do not endorse this project.

* **CommonCatalog, CC-BY subset** (https://huggingface.co/datasets/common-canvas/commoncatalog-cc-by), the photograph
  collection of the CommonCanvas project (Gokaslan et al., "CommonCanvas: An Open Diffusion Model Trained with
  Creative-Commons Images", 2023). These are photographs their authors published on Flickr under Creative Commons
  Attribution (CC BY) licences. They were read from a 512-pixel repackaging of that subset
  (data-archetype/commoncatalog_cc_by_3m_512 on Hugging Face), whose captions were used to pick the prompt words
  (img/caps.py; the 4,096-entry word list is img/remote/night/words.json).
  Per-photo credits for these photographs are not included: the author, licence version and source page of every
  photograph are in the dataset's own records at the address above.
* **Open Images V7** (https://storage.googleapis.com/openimages/web/index.html): close-up crops of named things
  (img/oi.py). The photographs are licensed CC BY 2.0 (https://creativecommons.org/licenses/by/2.0/); the object
  boxes used to cut the crops are by Google LLC, licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
  The author and Flickr page of every Open Images photograph used are listed in
  [img/web/itch/credits-openimages.txt](img/web/itch/credits-openimages.txt) (322,071 photographs). Where an author's
  recorded name was an e-mail address, only the part before the @ is given.

The same text ships with the browser version as img/web/itch/CREDITS.txt (inside pocketpix-web.zip).

Optional data paths in the code that were **not** used for the shipped models: img/setup_box.sh with SPRITES=1 and
the examples at the top of img/data.py and img/train.py name two pixel-art sets on Hugging Face
(Angais/pixel-art-atlas-1.4m, azyg0s/pixelart-172k) and CIFAR-10. Nothing from them is included here, and none of
the shipped weights was trained on them (each model's training set is named in its img/remote/night/<name>.json).

## Experimental distillation scripts
img/distill.py, img/flux_gen.py and img/jobs/x_*.sh download and run **FLUX.1-schnell** by Black Forest Labs
(Apache 2.0) to draw training pictures (img/DISTILL.md). No FLUX weights, FLUX pictures or weights fine-tuned on them
are included. img/flux_official.json lists the file names and SHA-256 fingerprints of the official FLUX.1-schnell
repository, used to check the download.
